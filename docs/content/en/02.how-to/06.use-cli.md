RustO! comes with a high-performance command line interface (CLI) binary for desktop OCR, terminal workflows, and automated CI pipelines.

## Installation & Building

Build the CLI directly from source with Release optimizations:

```bash
cargo build --release
```

The compiled binary will be located at `target/release/rusto`. You can optionally install it into your `$PATH`:

```bash
cargo install --path .
```

---

## 1. Basic CLI Invocations

```bash
rusto --det-model models/det.rten --rec-model models/rec.rten --dict models/dict.txt receipt.jpg
```

## 2. CLI Options Reference

| Option            | Flag              | Type   | Default  | Description                                                      |
| ----------------- | ----------------- | ------ | -------- | ---------------------------------------------------------------- |
| Detection Model   | `--det-model`     | `Path` | Required | Path to DBNet detection model file (.rten or .onnx).             |
| Recognition Model | `--rec-model`     | `Path` | Required | Path to CTC recognition model file (.rten or .onnx).             |
| Dictionary        | `--dict`          | `Path` | Required | Path to character vocabulary dictionary text file.               |
| Output Format     | `-f`, `--format`  | `Enum` | `json`   | Output mode (`json`, `text`, `tsv`, `markdown`, `text-ordered`). |
| Orientation       | `--enable-orient` | `Flag` | `false`  | Run whole-page orientation detection (functional since 0.4.0).   |
| Orient Model      | `--orient-model`  | `Path` | `models/DocOCR/orient_rapidai_v2.rten` | RapidAI v2 orientation model (.rten or .onnx). Requires `--enable-orient`; using it alone is a CLI error since 0.4.0. |
| Layout            | `--enable-layout` | `Flag` | `false`  | Document pipeline: regions, reading order, Markdown. Needs `--format document` or `markdown`. |
| Layout Model      | `--layout-model`  | `Path` | `models/DocOCR/layout_ppdoclayoutv3.rten` | PP-DocLayoutV3 model. Requires `--enable-layout`. |
| Table             | `--enable-table`  | `Flag` | `false`  | Recover table structure. Requires `--enable-layout`.             |
| Table Model       | `--table-model`   | `Path` | `models/DocOCR/table_slanetplus.rten` | SLANet_plus model. Requires `--enable-table`. |
| Save Corrected    | `--save-corrected`| `Path` | `None`   | Write the orientation-corrected page (PNG or JPEG, by extension). Requires `--enable-layout`. |

The output format `document` (JSON with regions, orientation, stages) is only valid with `--enable-layout`. A document or markdown run still prints its full output when a stage fails, writes `warning: stage <name> failed: <reason>` to stderr for each failed stage and exits with code `3` (`0` success, `1` error, `2` invalid command line). See [Document Layout, Tables & Orientation](/en/advance-guide/document-layout-and-tables) for models, coordinate space and limitations.

## 3. Output Formats with Real Examples

### 1. JSON (`--format json`)

Outputs structured JSON with bounding polygon quads and axis-aligned bounding frames:

```bash
rusto --det-model det.rten --rec-model rec.rten --dict dict.txt --format json receipt.jpg
```

```json
[
  {
    "text": "COFFEE SHOP",
    "score": 0.992,
    "box_points": [
      [95.0, 30.0],
      [275.0, 30.0],
      [275.0, 55.0],
      [95.0, 55.0]
    ],
```

### 2. Formatted Spatial Layout (`--format text-ordered`)

Preserves tabular columns, receipt rows, and document indentations:

```bash
rusto --det-model det.rten --rec-model rec.rten --dict dict.txt --format text-ordered invoice.jpg
```

```text
Item Description           Qty       Price       Total
Mechanical Keyboard          1     $120.00     $120.00
Wireless Mouse               2      $45.00      $90.00
USB-C Hub                    1      $35.00      $35.00
──────────────────────────────────────────────────────
Total Amount:                                  $245.00
```

### 3. Tab-Separated Values (`--format tsv`)

Ideal for shell scripting and piping into `awk`, `cut`, or spreadsheets:

```bash
rusto --det-model det.rten --rec-model rec.rten --dict dict.txt --format tsv receipt.jpg
```


## 4. Shell Integration & Batch Processing

### Piping into `jq` for JSON Processing

Extract high-confidence text lines:

```bash
rusto --det-model det.rten --rec-model rec.rten --dict dict.txt receipt.jpg | \
  jq -r '.[] | select(.score > 0.95) | "\(.text) (\(.score * 100 | round)%)"'
```

### Batch Scanning an Entire Directory

Scan all `.jpg` and `.png` images in parallel using `xargs`:

```bash
find ./scans -type f \( -name "*.jpg" -o -name "*.png" \) | \
  xargs -I {} -P 4 rusto --det-model det.rten --rec-model rec.rten --dict dict.txt --format text-ordered {}
```
